### 术语说明

- **Action（动作）**：工作流中的执行单元
- **Node（节点）**：Action的基类，可组成链表
- **Pipeline（管道）**：多个Action的有序组合
- **Context（上下文）**：全局共享的状态和配置
- **Scope（作用域）**：global（全局协调）或local（单机器人）
- **Skill Tree（技能树）**：函数的依赖关系树

## 💡 学习建议

### 1. 理解设计思想

GenSwarm采用的核心思想：
- **可组合性**：小的Action组合成复杂Pipeline
- **可扩展性**：通过继承轻松添加新功能
- **可恢复性**：状态序列化支持中断恢复
- **自愈性**：错误自动检测和修复

### 2. 关注关键抽象

系统的几个关键抽象：
- **ActionNode**：所有动作的基础
- **WorkflowContext**：全局状态管理
- **FunctionTree**：函数依赖管理
- **Handler**：错误处理抽象

### 3. 追踪数据流

理解数据如何在系统中流动：
```
用户指令 → Prompt → LLM → 响应 → Parser → 
Context → 下一个Action → ... → 生成代码
```
